# 《丛林之书》故事梗概

西奥尼山的狼群收养了人孩莫格利，他在棕熊巴鲁、黑豹巴希拉的教导下习得丛林法则，举起人类的"红花"斗败老虎谢尔汗，却因人狼两族都不容他而独自狩猎。本书还收录白海豹科蒂克寻岛、猫鼬里基—蒂基—塔维战眼镜蛇、大象图迈观象舞等名篇——吉卜林《丛林之书》第一部的全部七个散文故事。
