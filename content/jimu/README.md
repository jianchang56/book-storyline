# 《吉姆》故事梗概

拉合尔街头的爱尔兰孤儿吉姆，陪一位寻找"箭河"的西藏喇嘛踏上朝圣之路，又因一封密报被卷入英俄"大博弈"的谍战旋涡。他受训成为测量局最年轻的密探，在雪山截下俄国间谍的全部测绘文件；喇嘛则在平原的一条溪流里找到了箭河。师徒二人同获解脱，少年也在两种命运之间找到了自己的位置。
