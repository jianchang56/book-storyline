# 《搜神记》故事梗概

东晋干宝编撰的志怪小说集，全书二十卷，汇集上古至魏晋的神仙方术、灾异符瑞、梦占鬼事、精怪变化与因果报应，被尊为中国志怪小说的鼻祖。董永遇仙、干将莫邪三王墓、韩凭夫妇相思树、李寄斩蛇、东海孝妇、宋定伯卖鬼等无数后世传说的源头，都在这部书里。本书梗概按卷编排，每卷点名代表作并概述全卷内容。
