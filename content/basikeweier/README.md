# 《巴斯克维尔的猎犬》故事梗概

巴斯克维尔家族的魔犬传说笼罩着达特穆尔沼地。查尔斯爵士深夜惊死于庄园紫杉小径尽头，现场留有巨型猎犬的脚印；继承人亨利·巴斯克维尔自加拿大归来，警告信、跟踪与失窃接踵而至。福尔摩斯与华生深入阴森的庄园与吞人的泥潭，层层拨开巴里莫尔夫妇的烛光信号、斯台普吞兄妹的暧昧阻挠与劳拉·莱昂斯的失约之谜，最终在浓雾之夜击毙涂着磷光的巨犬，揭开一场借传说行凶的遗产阴谋。
