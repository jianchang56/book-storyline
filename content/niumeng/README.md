# 《牛虻》故事梗概

青年意大利党人亚瑟·伯顿因忏悔泄密被捕，又得知自己是蒙泰尼里神甫的私生子，信仰崩塌后假死出走南美。十三年后他化身讽刺作家"牛虻"里瓦雷兹归来，笔战教会、走私军火，与已是红衣主教的生父蒙泰尼里在狱中相认对决，最终推开十字架慷慨就义，蒙泰尼里也在圣体节的祭坛前当众崩溃。
