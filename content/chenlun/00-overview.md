# 《沉沦》：2 分钟全书速览

一个中国留学生在日本 N 市的高等学校求学。他三岁丧父，在富春江畔的书斋里孤独长大，少年时因不满教会学校的专制退学，忧郁症由此种下。随长兄赴日后，他听命弃文改医，来到 N 市。性情早熟孤冷的他自觉与世人隔绝：把日本同学当作仇敌，事后又自悔苛求同情；路上遇见女学生不敢开口，回旅馆痛骂自己卑怯，当夜在日记里哀叹——不要知识名誉，只求一个真心爱他的异性。

在 N 市，他陷入无法摆脱的性苦闷：每晚"犯罪"，事后痛悔立誓，次日又复犯。医书说此症最伤身体，他恐惧日增、身体衰弱，怕见妇人，又疑心中国同学说他有神经病，与所有人视同仇敌。旅馆主人十七岁的女儿是他唯一的牵挂，他却当面装作不可犯；一晚偷看她入浴被发觉，他连夜逃出旅馆，躲进山间一座无人梅园独住。搬入梅园后，他又为细事与北京的长兄决裂，发信绝交，把医科改回文科以示宣战。

沉沦步步加深：他在园中偷听男女幽会，痛骂自己下流却一句不肯遗漏；失魂落魄地渡海进了一家有妓女的酒楼，被侍女问及籍贯时不得不自认"支那人"，悲愤发抖。酒醉醒后，他倾囊付账，在海边月光下决意投海，朝着故国方向的明星长叹："祖国呀祖国！我的死是你害我的！你快富起来！强起来罢！"一个敏感而病弱的灵魂，就此沉没在异国的海里。
