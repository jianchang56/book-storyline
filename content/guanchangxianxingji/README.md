# 《官场现形记》故事梗概

晚清官场群丑图：从佐杂小吏到军机中堂，卖官鬻爵、贪污钻营、媚外欺内，六十回连缀起一部没有主角的百态故事集。上海办机器的骗局、严州“剿匪”的杀良冒功、京城军机房与太监门路的明码标价、赈捐与家产生意里的连环吞骗，一路看到对外交涉的卑躬屈膝，收场只留下一句“虽不能引之为善，却可以戒其为非”。
