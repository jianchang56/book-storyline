# 《绿野仙踪》故事梗概

明嘉靖年间，才子冷于冰因不肯依附严嵩被黜落科场，看破红尘弃家访道，得火龙真人传授仙法后斩妖除魔、济世度人，收连城璧、金不换、温如玉、锦屏、翠黛、袁不邪为徒，暗中促成严嵩父子的覆灭，最终功德圆满、师徒同登仙籍。神魔主线之外，温如玉与金钟儿、周琏与齐蕙娘的世情故事写尽贪欲痴迷的代价。
