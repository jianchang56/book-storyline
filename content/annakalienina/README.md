# 《安娜·卡列尼娜》故事梗概

安娜·卡列尼娜为弗龙斯基抛夫弃子，在上流社会的排斥与爱情的消磨中一步步走向卧轨；与之平行，地主列文求婚受挫后重返乡间，最终娶得基蒂，在劳作、婚姻与信仰追问中安放人生。托尔斯泰以这条毁灭与救赎的双线，写尽十九世纪俄国的爱情、家庭与生命意义。
