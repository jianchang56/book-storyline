# 《气球上的五星期》故事梗概

1862年，弗格森博士乘"维多利亚号"气球自桑给巴尔出发，带着神枪手迪克·肯尼迪和仆人乔，用五星期自东向西横越非洲大陆：确认尼罗河源头，夜战食人部落，沙漠中断水濒死，乍得湖上乔跃湖救友，最终在塔里巴追兵的枪口下越过古伊纳瀑布，抵达塞内加尔。这是儒勒·凡尔纳的第一部长篇小说。
