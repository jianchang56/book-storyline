# 《红与黑》故事梗概

维里埃尔木匠之子于连·索雷尔精通拉丁文、心怀拿破仑式的野心，从市长府的家庭教师做到巴黎拉莫尔侯爵的秘书。他与德·雷纳尔夫人的私情、与侯爵之女玛蒂尔德的爱情博弈把他推向功名的顶点，一封揭发信却断送一切——教堂枪击、审判与处决，构成这个"农民反抗自己卑贱出身"的悲剧。
