# 《浮生六记》故事梗概

清代沈复以自传体回忆平生。他少年订下与表姐陈芸（芸娘）的婚约，婚后夫妇沧浪亭畔论诗盟誓，把清贫日子过出雅致；旋因家事失欢于公婆被逐，憨园之约不遂、芸血疾缠身，最终债逼深宵离散、芸执手连呼"来世"而逝；沈复浪游三十年，江海行役以慰丧妻之痛。原书六卷，今存《闺房记乐》《闲情记趣》《坎坷记愁》《浪游记快》四卷。
