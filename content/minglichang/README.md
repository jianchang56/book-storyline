# 《名利场》故事梗概

十九世纪初的英国，孤女蓓基·夏泼不择手段向上爬：猎婚乔斯失败，转而笼络克劳莱一家、与浪荡军官罗登秘密成婚，战后靠赌技与赊账混迹上流，攀附斯丹恩勋爵觐见国王，又在私情败露后身败名裂。与她命运交错的是温顺的爱米丽亚·赛特笠：家道中落、违命嫁给乔治·奥斯本，滑铁卢的炮火让她成了寡妇，在贫病中守着儿子与回忆苦熬多年，直到忠心的都宾上尉终于等到她回头。滑铁卢前后，名利场中众生浮沉，无人是真正的英雄。
