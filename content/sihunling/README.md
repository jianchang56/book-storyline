# 《死魂灵》故事梗概

八等文官乞乞科夫走遍乡野，向各色地主收购名册上尚存、实则已死的农奴，打算假称迁往赫尔松垦殖、再拿名册向国库抵押套现；骗局轰动全城后他仓皇遁走。第二部残稿写他多年后的新冒险、置产与落网——原稿多处脱漏并至此中断，全书未完。
