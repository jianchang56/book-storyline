# 《诺桑觉寺》故事梗概

爱看哥特小说的乡村姑娘凯瑟琳·莫兰随艾伦夫妇初入巴斯社交场，结识风趣的牧师亨利·蒂尔尼，又卷入索普兄妹的虚荣与算计。做客古修道院改建的诺桑觉寺时，她把恐怖小说的想象套进现实，疑心将军谋害亡妻，直到被亨利点破；经历深夜逐客的羞辱与真相大白后，她放下幻想、长出自己的判断，与亨利终成眷属——这是奥斯汀最早写成的小说，一部戏仿哥特传奇的成长故事。
